# 🎬 مصنع رندر الفيديوهات القصيرة — GitHub Render

مستودع عام فيه كيت `cartoon-audio-short` وخط أنابيب **GitHub Actions** كيرندر
فيديوهات كرتون عمودية (1080×1920) **بالتوازي**: الإطارات كتقسّم على عدة مهام
كتخدم في نفس الوقت، وفي الأخير كتجمع وكتخرّج MP4 جاهز.

> ⚠️ **هاد المستودع خاصو يبقى PUBLIC** — المستودعات العامة عندها دقائق
> Actions مجانية وبلا حد. المستودع الخاص محدود بـ2,000 دقيقة في الشهر.

## شنو فيه

| المجلد | شنو |
|---|---|
| `kit/` | محرك الرندر (three.js + Chromium) وأدواته: `setup.sh` كيبني مشروع، `render.mjs` كيرندر الإطارات، `finish.sh` كيخرّج الفيديو |
| `projects/<name>/` | ملفات كل فيديو: `story.js` + `mix_raw.wav` (+ اختياريا `web/` مخصّصة) — الشرح الكامل في `projects/PROJECT-LAYOUT.md` |
| `.github/workflows/render.yml` | خط الأنابيب: تقسيم ← رندر متوازٍ ← تجميع وتشطيب |

## كيفاش تشغّل الرندر

1. تأكد أن مجلد المشروع موجود في `projects/<name>/` وفيه `story.js` و`mix_raw.wav`.
2. روح لتبويب **Actions** ← اختر **Parallel Render** ← **Run workflow**.
3. عمّر المدخلات:
   - **project**: اسم مجلد المشروع (مثال: `hero-doors`)
   - **total_frames**: عدد الإطارات الكلي = مدة الصوت بالثواني × 30 (مثال: 42.3 ثانية ← `1270`)
   - **chunks**: على شحال من مهمة متوازية يتقسّم الرندر (الافتراضي `8`)
   - **title**: عنوان الفيديو — غادي يكون اسم ملف الـMP4
4. صبر حتى تسالي كل المهام (الرندر هو أطول مرحلة).

## فين تلقى الفيديو الجاهز

افتح تشغيل الـworkflow اللي سالا ← لتحت في **Artifacts** ← نزّل **`final-video`**
(فيه الـMP4 النهائي). الإطارات الوسيطة (`frames-*`) كتبقى يوم واحد غير باش
تجمعها مهمة التشطيب، ومن بعد كتمسح بوحدها.

## ملاحظات مهمة

- 🔒 **الصوت الأصلي (الفويس أوفر) ما كيدخلش للمستودع أبداً** — كيبقى عند Rio
  في الجهاز المحلي. اللي كيطلع غير `mix_raw.wav`: الخلط النهائي واجد
  (الموسيقى والمؤثرات على −6 dB تحت الصوت).
- 🔁 إلا عاودتي تشغيل مهمة رندر، `RESUME=1` كيخليها تكمل غير الإطارات الناقصة.
- 🧩 كل مشروع كيتبنى محلياً أولاً (توقيت، لقطات تجريبية، خلط) — السحابة غير
  كترندر الإطارات وكتشطّب.
